# Student Management Backend System

A backend application that provides APIs and server-side functionality for managing student records and supporting the Student Management System frontend.

## Features

- ➕ Add new student records
- 📋 Retrieve student information
- 🔍 Search and filter student records
- ✏️ Update student information
- 🗑️ Delete student records
- 🔐 API-based data management
- ⚙️ Server-side validation and error handling
- 🔗 Frontend API integration
